### 1\.1 DNESP32S3 开发板资源初探

ESP32 系列芯片自 2016 年发布以来，经过多年的发展，已经成为了物联网领域的重要选择。该系列芯片不断升级和完善，支持更多的应用场景和功能，因此受到广泛欢迎。最新的 ESP32S 系列芯片进一步丰富了该系列的产品线，满足了不同领域的需求。为了满足大家对 AIOT 功能的需求，正点原子推出了 HMI 与典型的学习板相结合的 DNESP32S3 开发板，为开发者提供了一个全面、易用的开发环境。该开发板结合了图形界面和典型学习版的功能，让开发者能够更方便地进行开发和学习。

#### 1\.1\.1 DNESP32S3 硬件设计特点

DNESP32S3 开发板硬件设计特点包括：

1. **接口丰富**：板子提供十来种标准接口，可以方便的进行各种外设的实验和开发。

2. **设计灵活**：板上很多资源都可以灵活配置，以满足不同条件下的使用。我们引出了数十个 IO 口，可以极大的方便大家扩展及使用。

3. **资源充足**：主控模组采用正点原子提供的 ATK‑MWS3S \(和乐鑫官方 ESP32S3‑WOODN16R8 对应\)，自带 384K ROM \(存储官方启动固件，开发者无法使用\)、512K SRAM、16MB FLASH 和 8MB PSRAM，满足大数据存储需求。

4. **人性化设计**：各个接口都有丝印标注，且用方框框出，使用起来一目了然；部分常用外设大丝印标出，方便查找；接口位置设计合理，方便顺手。资源搭配合理，物尽其用。

5. **国产化程度高**：为了支持国产芯片的发展和推广，正点原子优选国产好芯，DNESP32S3 开发板上凡是能用国产替代的芯片，全部使用国产芯片，国产化率达到 98% \(数量\)。

### 1\.2 DNESP32S3 开发板资源说明

DNESP32S3 资源说明，我们将分为两个部分：硬件资源说明和 DNESP32S3 IO 引脚分配。

#### 1\.2\.1 硬件资源说明

这里我们详细介绍 DNESP32S3 开发板的各个部分，按逆时针顺序介绍：

1. **USB 转串口 \(USB\_UART Type‑C\)**
这是开发板板载的另外一个 Type‑C USB 头，用于 USB 连接 CH340 芯片，实现 USB 转 TTL 串口。同时，此接头也是开发板电源的主要提供口。

2. **红外接收头 IR**
开发板红外接收头，可以实现红外遥控功能，可以接收市面常见遥控器红外信号，可做万能红外解码，也可以用来传输数据。配套正点原子红外遥控器。

3. **SPILCD 模块 / WIRELESS 模块接口 \(U2\)**
外接 NRF24L01、RFID、正点原子 1\.3 寸 SPI LCD、2\.4 寸 SPI LCD 模块。实现屏幕显示和无线通信。

> 注意：NRF24L01 无线通信，必须 2 套模块 \+ 2 块开发板，单块无法测试。
> 
> 

4. **红外发送头 IR1**
开发板红外发送头，可以发送标准红外编码，模拟红外遥控器发射信号。

5. **USB SLAVE\(JTAG Type‑C\)**
Type‑C 接口，用于 ATK‑MWS3S 模组 USB 从机通信，可做 JTAG 下载调试。

6. **摄像头模块接口 P2**
OLED / 摄像头二合一接口，可插接正点原子 OV 系列摄像头模块。

7. **光环境三合一传感器 U5 \(AP3216C\)**
环境光传感器、接近传感器、红外传感器三合一。感知环境光线、物体接近距离，可以实现屏幕自动背光调节，IIC 接口。

8. **有源蜂鸣器 BEEP**
实现报警、提示音。BEEP 信号连接 XL9555 IO 扩展芯片 P0\_3 引脚，需要 IIC 操作 XL9555 间接控制蜂鸣器。

9. **三轴加速度传感器 QMA6100P**
低功耗高精度三轴加速度，姿态检测。

10. **DS18B20/DHT11 复用接口 U4**
4pin 排座，单总线接口。支持 DS18B20 数字温度传感器、DHT11 温湿度传感器。数据线连接 IO0。

11. **红色 LED 指示灯**
板载红色 LED，IO1 控制，调试程序状态指示，大量例程使用该 LED。

12. **复位按键 RESET**
复位 ATK‑MWS3S 模组，同时复位外接液晶模块。液晶复位引脚和模组复位引脚共接。

13. **5 个机械按键 KEY0、KEY1、KEY2、KEY3、BOOT**
KEY0‑KEY3：经过 XL9555 IO 扩展读取，低电平有效；
BOOT 按键：模组启动模式选择，运行后可做普通按键，低电平有效，接 IO0。

14. **PWR 电源指示灯 \(蓝色 LED\)**
板载蓝色 LED，板载电源开关打开后点亮，判断开发板上电状态。

15. **多功能接口 P3 \(4pin 排针\)**
跳线帽配置：

- 1‑2 短接：ADC 采集功能；

- 2‑3 短接：RMT 红外发送输出；
支持多种复用功能。

16. **MIC 咪头**
板载录音输入，直接接入 ES8388 音频 CODEC，实现录音功能。

17. **PHONE 3\.5mm 耳机接口**
ES8388 音频输出，可插入耳机播放音频。

18. **3\.3V 电源输入输出接口**
对外输出 3\.3V，也可外部给开发板输入 3\.3V 供电。

19. **板载扬声器**
8Ω 1W 喇叭，MD8002A 功放芯片驱动，最大输出 3W。注意 USB\_SLAVE 和喇叭功放共用 PA11/PA12，二者不可同时使用。

20. **TF 卡 \(MicroSD 卡\) 接口**
SPI 驱动 TF 卡，最大 TB 级容量，用于海量数据存储。**TF 卡与 SPILCD 共用一路 SPI 总线。**

21. **IO 引出排针 P1/P3/P4/P5**
四组排针引出，除去电源 GND，共 28 个可用 IO。

22. **RGB‑LCD 接口 J1**
RGB565 屏幕接口，支持正点原子 4\.3 寸 RGB 屏，带触摸接口。

23. **USB 串口 / 串口 0 跳线接口 P4**
U0RX、U0TX 为模组串口 0；TXD/RXD 是 CH340 USB 转 TTL。跳线帽连接，实现下载程序和串口调试。拔掉跳线帽：

- 开发板作为 USB‑TTL 转接板给外部设备用；

- 外部 TTL 串口可以直接和 ESP32‑S3 模组通信。

24. **ATK 通用模块接口 U3**
6pin 排座，直接插正点原子模块：GPS、蓝牙、LORA、MPU6050、手势识别、激光测距模块。

25. **CH340C 芯片**
USB 转 TTL 芯片，无需外部晶振，实现 USB 下载、串口调试。

## 第二章 实验平台硬件资源详解

本章详细讲解 DNESP32S3 各部分硬件原理图，理解硬件原理。分为 2\.1 开发板原理图详解；2\.2 开发板使用注意事项。

### 2\.1 开发板原理图详解

#### 2\.1\.1 模组 ATK‑MWS3S

主控模组 ATK‑MWS3S：

- ROM：384KB

- SRAM：512KB

- FLASH：16MB

- PSRAM：8MB

- 主频：240MHz

- 支持 KPU 神经网络加速。
模组为低电平复位。

#### 2\.1\.2 引出 IO 口

4 组排针：P1 \(2*12 单排针\)，P3 \(1*4\)，P4\(2*3 双排针\)，P5 \(2*3 双排针\)。除去电源 GND，可用普通 IO 数量**28 个**。

> IO 不够用：可以把摄像头座子替换为排针，扩展更多 IO。
> 
> 

#### 2\.1\.3 USB 串口 / 串口 0 选择接口 \(P4 跳线帽\)

- CH340 端：TXD、RXD；

- ESP32‑S3 模组端：U0TX、U0RX；
跳线帽短接，实现 USB 串口下载调试。拔掉跳线帽，可以实现：

1. 外部 TTL 串口和 ESP32‑S3 通信；

2. ESP32‑S3 开发板充当 USB 转 TTL 适配器给其他外部电路板使用。

#### 2\.1\.4 LCD 模块 \& WIRELESS 模块接口 U2

U2 为 8pin 插座，支持：

- NRF24L01 无线模块；RFID 模块；

- 正点原子 1\.3 寸 /2\.4 寸 SPI‑LCD 屏幕；
信号包含 SPI\_SCK、SPI\_MOSI、CSN、CE、IRQ、RST、PWR 等。

#### 2\.1\.5 复位电路

10K 上拉电阻，RESET 按键按下拉低复位。**低电平复位**。复位信号同时给到 ESP32‑S3 模组以及外接 SPI‑LCD 屏幕。

#### 2\.1\.6 EEPROM\(24C02\)

24C02，容量 2Kbit \(256 字节\)。IIC 总线，A0/A1/A2 全部接地，I2C 器件地址为 0。硬件兼容 24C02\~24C512 全系列 EEPROM。

#### 2\.1\.7 温湿度传感器接口 U4

单总线接口。数据线`1WIRE_DQ`接 IO0。支持 DS18B20、DS1820、DHT11。

#### 2\.1\.8 光环境传感器 AP3216C

三合一传感器：光照强度、接近距离、红外强度。IIC 接口，SDA 接 IO41，SCL 接 IO42。

#### 2\.1\.9 红外接收头 LF0038GKLL‑1

通用红外接收头，输出`REMOTE_IN`信号接 IO2。1N4148 二极管隔离保护。3\.3V 供电。接收各种标准遥控器编码。

#### 2\.1\.10 红外发送头

MOS 管 SI2302 驱动红外发射 LED，控制信号`REMOTE_OUT`接 IO8。IO8 输出 PWM \(RMT 外设\)，调制发射红外遥控编码。

#### 2\.1\.11 LED 指示灯

- **RED LED**：状态 LED，串联 510Ω 限流，由 IO1 输出控制；

- **BLUE PWR LED**：电源指示灯，上电即亮，不受软件控制。

#### 2\.1\.12 按键电路

- KEY0\~KEY3：按键按下直接 GND，信号输入到 XL9555 IO 扩展芯片；

- BOOT 按键：按下接地，接到 IO0，上电时刻可以进入下载模式；程序运行时，可以做普通按键输入。全部按键低电平有效。

#### 2\.1\.13 摄像头模块接口 P2

OV 系列摄像头插座。8 位 D0‑D7 数据，PCLK、HREF、VSYNC、PWDN、RESET；I2C SDA/SCL 带上拉 4\.7K 电阻。支持正点原子 OV2640 摄像头。

#### 2\.1\.14 有源蜂鸣器

有源蜂鸣器，通电直接鸣叫。BEEP 信号来自 XL9555 扩展芯片 P0\_3 引脚，Q1 三极管扩流驱动。R7 限流电阻，防止复位瞬间蜂鸣器误响。

> 有源蜂鸣器：上电即响；无源蜂鸣器需要 2‑5KHz 方波驱动。本板使用有源。
> 
> 

#### 2\.1\.15 TF 卡接口

SPI 模式驱动 TF 卡，最高 24MB/s 读写。⚠️**TF 卡 SPI 总线和 SPILCD 模块接口 SPI 总线共用**，不能同时高速工作。

#### 2\.1\.16 ATK 模块接口 U3

6pin 通用 ATK 模块插座，直插正点原子系列模块：GPS、蓝牙、MPU6050、LORA、手势识别、激光测距。

#### 2\.1\.17 多功能端口 P3 \(4pin\)

- 跳线帽 1‑2 接通：电位器 RV1 滑动端接入 ADC 输入；

- 跳线帽 2‑3 接通：RMT 红外发送输出；
仅需要调整跳线帽切换不同功能。

#### 2\.1\.18 电源电路

- LDO 芯片 RT9013‑33GB：5V 转 3\.3V；

- K1 总电源开关；F1：1000mA 自恢复保险丝，保护 USB 供电回路。

#### 2\.1\.19 电源输入输出接口 VOUT1 \(3\.3V\) VOUT2 \(5V\)

- 既可以开发板向外输出 3\.3V/5V，最大 500mA；

- 也可以外部电源通过 VOUT 接口给开发板供电。

- TVS 管 SMFJ5\.0CA / SMFJ3\.3CA：浪涌保护，防止外接感性负载 \(电机继电器\) 倒灌损坏板子，同时防电源反接。

#### 2\.1\.20 USB\_Slave\(JTAG Type‑C\)

USB 从机接口，支持 USB‑CDC、MSC、HID 设备；同时复用为 JTAG 硬件调试接口。D‑接 IO19，D \+ 接 IO20。

#### 2\.1\.21 USB\_UART\(CH340C\)

CH340C USB 转 TTL 芯片，不需要外部晶振。Type‑C 接口，既是 CH340 和电脑通信，也是开发板主要供电来源。VUSB 来自电脑 USB 口。

#### 2\.1\.22 音频编解码 ES8388

ES8388 立体声 24bit 音频 CODEC：

- DAC/ADC 最高 192K 24bit；

- 板载 MIC 咪头输入；3\.5mm 耳机 PHONE 输出；LINE‑IN 线路输入；

- 功放芯片 MD8002A 驱动板载 8Ω/1W 扬声器，最大输出 3W。

> ES8388 本身不带功放，耳机可以直推；喇叭必须经过 MD8002A 功放。
> I2S 引脚映射：
> 
> 

- I2S\_MCLK → IO3

- I2S\_SCK → IO46

- I2S\_LRCK → IO9

- I2S\_SDIN → IO10

- I2S\_SDOUT → IO14
IIC 配置总线 SDA \(IO41\)/SCL \(IO42\)，和 AP3216C、24C02 共用 IIC 总线。

#### 2\.1\.23 RGB‑LCD 接口 J1

J1 为 RGB‑LCD 插座，RGB565 格式，只支持正点原子 4\.3 寸 RGB 屏幕，带触摸接口。**不支持 MCU 模式 SPI LCD**。

### 2\.2 开发板使用注意事项

1. USB 单口供电最大 500mA，线材压降导致实际 5V 电压不足。当同时驱动 LCD、多个外设，负载大，建议同时插上两个 Type‑C USB，提升供电能力。

2. 使用 IO 口前，查阅硬件手册，确认引脚板上是否已经挂载外设。例如 IO8 接红外发射电路，不适合做普通输入检测，容易被干扰。

3. 板子多处跳线帽，使用功能前确认跳线帽配置，避免调试踩坑。
